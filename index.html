BACKGROUND
背景介绍
低空安全威胁态势与防御需求
01
🛸 低空安全威胁态势
  • 消费级无人机保有量超 300 万架，年增长率 >30%
  • 「低慢小」RCS 0.001–0.1m²，探测难度极大
  • 高度 <1000m，速度 10–150km/h，机动灵活
  • 传统防空雷达虚警率高，城市多径反射
  • 集群攻击（Swarm）防御难度上升
  • FPV 穿越机成本 <500 元，威胁门槛极低
02
⚠️ 滥用与实战威胁
  • 机场侵入：2017 年成都双流 58 架备降
  • 军事侦察：非法航拍基地等高价值目标
  • 恐怖袭击：携带爆炸物精确打击
  • 电磁干扰：蓄意干扰通信/GPS
  • 集群饱和：数十架同时突防
  • 蜂群协同：多机组网动态规避
03
📋 法规政策与产业需求
  • 《无人驾驶航空器飞行管理暂行条例》2024 施行
  • 民航局要求重点场所配备反无人机系统
  • 低空空域管理改革催生监管刚需
  • 大型活动安保反无人机需求激增
  • 军队要地防空向低慢小延伸
  • eVTOL 城市空中交通需要配套监管

AIRSPACE // DESIGN
空域管理 — 分系统设计
低空空域身份识别与合法飞行验证
📡 身份识别方式
  • Remote ID：WiFi/BLE 广播解析序列号/位置/高度
  • ADS-B：1090MHz 航空器广播信息
  • 飞控协议侦测：2.4/5.8G 分析提取机型和 ID
✅ 合法性验证
  • 登记查询：对接民航局无人机登记系统
  • 计划核验：飞行计划航线/高度/时段比对
  • 围栏检查：电子围栏合规性检查
🎯 决策逻辑
  • 合法：已登记+已申报+轨迹一致→绿色
  • 可疑：已登记未申报/轨迹偏离→黄色
  • 非法：未登记未申报→红色→启动反制
⚠️ 轨迹比对与威胁分发
  • 实时比对：探测轨迹 vs 申报轨迹
  • 自动标记：超阈值自动标记异常
  • 信息推送：推送至拦截单元
🗺️ 空域态势显示
  • 2D/3D 态势图多图层叠加
  • 雷达/光电/空管/气象/地理信息
⚙️ 支撑技术
  • Remote ID ASTM F3411 协议
  • 多源数据融合联合验证
  • 时空轨迹相似度偏差检测
  • 动态地理围栏越界告警
  • UTM 无人机交通管理数据交换

拦阻截击 — 分系统设计
软杀伤优先、硬杀伤兜底的分级反制
⚡ 软杀伤（非动能）
  • 通信干扰：切断遥控链路
  • GNSS 诱骗：伪造卫星信号驱离
  • 协议阻断：飞行终止命令迫降
💥 硬杀伤（动能）
  • 激光反制：10–50kW 1–5km
  • 网捕无人机：捕获网拦截
  • FPV 拦截器：高速对撞/伴飞
⚙️ 支撑技术
  • 0.1–6GHz 可编程宽带干扰源
  • GPS/北斗/BDS 多星座诱骗
  • 自适应光学激光跟踪 1mrad
  • FPV 视觉+RTK 高速追击
  • 反制效果行为监测评估
📡 反制距离分层
距离手段场景
5–15km预警监测早期发现
3–5km通信干扰先警告后干扰
1–3kmGNSS 诱骗强制驱离
0.5–1km激光反制高威胁摧毁
0–0.5km网捕/FPV近距兜底
🎯 分级决策流程
  • 识别→等级评估（1–5 级）
  • 1–2 级：通信干扰驱离
  • 3 级：GNSS 诱骗转向
  • 4–5 级：激光/FPV 拦截
  • 人工确认 与 自动执行 双模式
  • 反制前评估 附带影响
