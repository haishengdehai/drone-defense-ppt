BACKGROUND
背景介绍
低空安全威胁态势与防御需求
🛸 低空安全威胁态势
  • 消费级无人机保有量超 300 万架，年增长率 >30%
  • 「低慢小」目标 RCS 仅 0.001–0.1m²，探测难度极大
  • 飞行高度低（<1000m），速度小（10–150km/h），机动灵活
  • 传统防空雷达针对高速大目标，对低慢小虚警率高
  • 城市环境多径反射、杂波干扰，信噪比恶劣
  • 无人机集群攻击（Swarm）兴起，防御难度指数上升
  • FPV 穿越机成本极低（<500 元），威胁门槛极低
  • 夜间、雾霾、雨雪天气下探测能力显著下降
⚠️ 无人机滥用与实战威胁
  • 机场侵入：2017 年成都双流机场致 58 架航班备降
  • 军事侦察：非法航拍军事基地、雷达站等高价值目标
  • 恐怖袭击：携带爆炸物、化学制剂实施精确打击
  • 走私贩毒：利用无人机跨境运输违禁品
  • 电磁干扰：蓄意干扰通信基站、GPS 导航
  • 集群饱和：数十架同时突防，单目标防御失效
  • 蜂群协同：多机自主组网，动态规避防御火力
  • 隐蔽渗透：低空慢速飞行，传统雷达难以发现
📋 法规政策与产业需求
  • 《无人驾驶航空器飞行管理暂行条例》2024 年施行
  • 民航局要求重点场所配备反无人机系统
  • 低空空域管理改革催生低空监管刚需
  • 《反恐怖法》要求关键基础设施建立低空安防体系
  • 大型活动安保（赛事、庆典）反无人机需求激增
  • 军队要地防空向低慢小目标延伸
  • eVTOL 城市空中交通需要配套监管体系

📐 架构设计原则
  • 模块化：子系统独立部署升级，标准接口互联
  • 分布式：边缘计算（FPGA/GPU）+ 中心服务器分级

  • 开放：支持第三方雷达、光电、空管接入
  • 安全：内外网物理隔离，符合等保要求
🔄 子系统接口
  • 雷达→服务器：UDP 点迹流 10Hz
  • 服务器→光电：TCP 指令队列 200ms
  • 光电→服务器：RTSP 视频流 + MQTT 元数据
  • 空管→服务器：RESTful API + WebSocket
  • 服务器→反制：优先级队列，人工/自动触发

AIRSPACE // DESIGN
空域管理 — 分系统设计
低空空域身份识别与合法飞行验证
📡 身份识别方式
  • Remote ID：WiFi/BLE 广播，解析序列号/位置/高度
  • ADS-B：1090MHz 航空器广播信息
  • 飞控协议侦测：2.4G/5.8G 协议分析，提取机型和操控者 ID
✅ 合法性验证
  • 登记查询：对接民航局无人机登记系统
  • 计划核验：飞行计划申报（航线/高度/时段）
  • 围栏检查：电子围栏合规性检查
🎯 决策逻辑
  • 合法：已登记+已申报+轨迹一致→绿色通行
  • 可疑：已登记但未申报/轨迹偏离→黄色预警
  • 非法：未登记+未申报→红色威胁→启动反制
⚠️ 轨迹比对与威胁分发
  • 实时比对：探测轨迹 vs 申报轨迹
  • 自动标记：超阈值偏差自动标记异常
  • 信息推送：威胁推送至拦截单元和终端
🗺️ 空域态势显示
  • 2D/3D 态势图，多图层叠加
  • 雷达/光电/空管/气象/地理信息
⚙️ 关键支撑技术
  • Remote ID ASTM F3411 协议
  • 多源数据融合联合验证
  • 时空轨迹相似度偏差检测
  • 动态地理围栏越界告警
  • UTM 无人机交通管理数据交换

拦阻截击 — 分系统设计
软杀伤优先、硬杀伤兜底的分级反制
⚡ 软杀伤（非动能）
  • 通信干扰：切断无人机与遥控器链路
  • GNSS 诱骗：伪造卫星信号驱离
  • 协议阻断：飞行终止指令迫降
💥 硬杀伤（动能）
  • 激光反制：10–50kW 高能激光 1–5km
  • 网捕无人机：捕获网拦截低威胁目标
  • FPV 拦截器：高速对撞或伴飞干扰
⚙️ 关键支撑技术
  • 0.1–6GHz 可编程宽带干扰源
  • GPS/北斗/BDS 多星座 GNSS 诱骗
  • 自适应光学激光跟踪 1mrad
  • FPV 视觉+RTK 高速追击控制
  • 目标行为监测反制效果评估
📡 反制距离分层
距离手段场景
5–15km预警监测早期发现
3–5km通信干扰先警告后干扰
1–3kmGNSS 诱骗+干扰强制驱离
0.5–1km激光反制高威胁目标摧毁
0–0.5km网捕/FPV近距兜底
🎯 分级决策流程
  • 威胁目标识别→等级评估（1–5 级）
  • 低威胁 1–2：通信干扰驱离
  • 中威胁 3：GNSS 诱骗转向
  • 高威胁 4–5：激光/FPV 拦截
  • 每级 人工确认 与 自动执行 双模式
  • 反制前评估 附带影响
